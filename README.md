The Last Beacon

When the safest route disappears, survival depends on your next decision.

The Last Beacon is an offline survival-coordination prototype built for a hackathon. Follow Aarav and Mira as they navigate a zombie-infested city, manage limited supplies, and search for a safe route to the final evacuation beacon.

When a sudden zombie horde blocks their planned path, players must choose between a safer detour, a dangerous alley, or retreating to a previous checkpoint. Every decision affects their stamina, supplies, and chances of survival.

Features

- Interactive city map: Explore locations, checkpoints, routes, and danger zones.
- Dynamic threat simulation: Encounter zombie hordes that can block planned routes.
- Alternative route planning: Choose between safer detours and riskier paths.
- Resource management: Track food, water, medkits, and batteries.
- Survivor monitoring: Monitor Aarav and Mira's health and stamina.
- Survival decisions: Balance risk, resource consumption, and progress.
- Offline functionality: Run the prototype locally without requiring an internet connection.

Tech Stack

- HTML5
- CSS3
- JavaScript

Getting Started

No installation or additional dependencies are required.

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Start exploring the map and making survival decisions.

Alternatively, use the VS Code Live Server extension to run the project locally.

How to Play

1. Review the survivor status and available supplies.
2. Examine the city map and choose your destination.
3. Watch for simulated zombie encounters and blocked routes.
4. Select an alternative route when your path becomes unsafe.
5. Manage food, water, health, and stamina carefully.
6. Make strategic decisions to guide Aarav and Mira toward safety.

Problem Statement

Build a survival-coordination prototype that helps two friends plan routes through a zombie-infested city, track essential supplies, identify dangerous zones, and coordinate their next moves without connectivity. The system must simulate changing threats and support survival decisions under resource constraints.

Future Improvements

- Smarter threat prediction and route recommendations.
- More detailed map navigation and location-based events.
- Persistent game progress and survivor inventory.
- Improved mobile responsiveness and accessibility.
- More realistic survival scenarios and resource dependencies.

Current Limitations

This is a prototype with simulated threats, routes, and resource changes. It does not use live zombie tracking, external mapping services, or a real AI prediction engine. Game state and events are handled locally in the browser.
